# Security policy

This project is pre-release and has not been security audited. Run it as your own user, not root. Future services must bind to loopback by default. Model paths, prompts and downloaded artifacts are untrusted inputs.

Do not post exploitable vulnerabilities or secrets in public issues. Once GitHub hosting is configured, use the repository's private vulnerability reporting feature. Until a private channel is published, do not assume there is a monitored security inbox. General hardening suggestions without sensitive details can be public issues.

Only the latest development revision is maintained at present. Never commit user databases, API keys, models or generated private material.
